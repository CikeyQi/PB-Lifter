# PB Lifter

[![Unity 2022.3](https://img.shields.io/badge/Unity-2022.3-000000?logo=unity)](https://unity.com/releases/editor/whats-new/2022.3.0)
[![VRChat Avatars SDK](https://img.shields.io/badge/VRChat%20Avatars%20SDK-3.7.0--3.10.x-1f9bf0)](https://vrchat.com/home/download)
[![NDMF](https://img.shields.io/badge/NDMF-1.8.x-5c5c5c)](https://github.com/bdunderscore/ndmf)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

PB Lifter 是面向 VRChat Avatar 的 [NDMF](https://github.com/bdunderscore/ndmf) 构建插件。它会在构建期间合并彼此兼容的 `VRCPhysBone` 组件，减少组件数量。它采用保守策略：只要无法合理判断合并是否合适，就会保留该 PhysBone，不会强行合并。

> [!IMPORTANT]
> PB Lifter 不会修改 Unity 场景中的 Avatar。它只会在 Avatar Root 上保存仅编辑器可用的构建计划，NDMF 仅将该计划应用到构建副本。扫描成功代表一项建议，并不证明构建结果与原 Avatar 完全一致；上传前务必在 VRChat 中测试构建后的 Avatar。

## 开始前

PB Lifter 适合拥有多个相似且相互独立 PhysBone 骨骼链的 Avatar，例如重复配件、发束或装饰链。第一次使用请保留默认设置。

若骨骼链有意设置为不同表现、由动画控制、需要交互，或碰撞体、约束、参数、权限设置不同，则通常不应期待它们被合并。默认保留这些组件是为了避免改变行为。

| 依赖 | 支持版本 |
| --- | --- |
| Unity | `2022.3` |
| VRChat Avatars SDK | `>= 3.7.0 < 3.11.0` |
| NDMF | `>= 1.8.0 < 2.0.0` |

添加 PB Lifter 前，请先在 Avatar 工程中安装 VRChat Avatars SDK 和 NDMF。

## 安装

### VCC

1. 在 VCC 中打开 **Settings > Packages > Add Repository**。
2. 添加以下仓库地址：

   ```text
   https://cikeyqi.github.io/PB-Lifter/vpm.json
   ```

3. 将 **PB Lifter** 添加到 Avatar 工程。

[一键添加到 VCC](https://cikeyqi.github.io/PB-Lifter/add-repo/)

### Unity package

从 [Releases](https://github.com/CikeyQi/PB-Lifter/releases) 下载 `PB-Lifter-<版本号>.unitypackage`，再将其导入兼容的 Avatar 工程。

## 安全使用流程

1. 打开 **Tools > PB Lifter > Optimizer Window**。
2. 指定 Avatar 的根 GameObject。
3. 第一次扫描时保留默认的**合并策略**、**容差规则**和高风险选项。
4. 点击**扫描并预览**。
5. 根据下面的说明检查**报告**和**诊断**页。
6. 确认方案可接受后，点击**确认：将构建计划附加到 Avatar 根节点**。
7. 按通常方式通过 NDMF 构建，并在 VRChat 中测试构建后的 Avatar。

只有预览确实能够减少 PhysBone 组件数时，确认按钮才会可用。附加计划不会修改源 PhysBone。每次调整计划、PhysBone 或 Avatar 层级后，都应重新打开窗口并扫描。

## 如何阅读预览

### 报告

报告会显示预计减少的组件数和每个计划合并组。打开一个组即可查看成员、受影响骨骼数，以及将被聚合的数值字段；使用**定位**可在层级中找到对应组件。

只有当组内成员本来就应有相近表现、且列出的聚合字段结果可以接受时，才应确认该组。若某条骨骼链无论如何都不想改动，请添加排除规则，而不是依赖某项设置恰好不兼容。

### 诊断

诊断会为每个 `VRCPhysBone` 显示**计划合并**或**不合并**，并列出未选中的首要原因。常见结果及处理方式如下：

| 诊断结果 | 含义 | 建议 |
| --- | --- | --- |
| 没有其他候选项与其共享有效根节点的父级 | 同一结构分组内没有兼容的同级候选项。 | 通常保持不变。仅为了合并而重挂骨骼可能改变骨架。 |
| 激活动画的切换根不同 | 骨骼链由不同的激活动画边界控制。 | 保持分开。此项不能放宽。 |
| PhysBone 的数值属性被动画驱动 | 动画正在写入 PhysBone 的某个数值设置。 | 保持分开。此项不能放宽。 |
| 某字段不同／差异超出容差 | 必需的设置不一致。 | 保持严格匹配；只有理解行为变化后才为该字段启用容差。 |
| 权限、碰撞体、参数、约束或多子节点模式不同 | 非数值行为设置不一致。 | 保持分开。高风险放宽只能跳过部分候选筛选，不能让不同设置变得兼容。 |
| 达到候选项或合并组受影响骨骼上限 | 当前大小限制阻止了合并。 | 先保留默认值；只有验证更大组安全后才提高对应上限。 |
| 已被自定义排除 | 该节点被你明确保护。 | 只有希望重新参与筛选时，才删除或缩小排除范围。 |

## 如何选择设置

### 合并策略

默认值偏向保守且可预测的分组：按受影响骨骼数加权平均、聚合值约束聚类、单候选项上限 `100`、单合并组上限 `128` 个受影响 Transform。

| 设置 | 适用场景 | 作用 |
| --- | --- | --- |
| 数值聚合：算术平均 | 希望每条链的权重相同。 | 写入已允许差异数值的普通平均值。 |
| 数值聚合：加权平均 | 希望较长的链影响更大。默认选项。 | 可等权，或按受影响骨骼数加权。 |
| 数值聚合：中位数 | 希望中间值不易受极端值影响。 | 写入已允许差异数值的中位数。 |
| 聚类算法：聚合值约束 | 希望在每个成员接近组聚合值的前提下获得更大分组。默认选项。 | 将新成员与当前聚合值比较。 |
| 聚类算法：完全链接 | 希望组内任意两个成员都在容差范围内。 | 更严格，通常产生更小的分组。 |
| 单个候选项受影响骨骼上限 | 已确认单条链在其他大小下也安全。 | 达到或超过上限的候选项不参与合并，最小值为 `1`。 |
| 每组合并受影响骨骼上限 | 已验证单个合并组可安全容纳更多或更少骨骼。 | 在上限处分割已通过筛选的候选项，最小值为 `2`。 |

### 容差规则

默认情况下，所有数值字段和曲线都必须严格一致。启用容差后，当某字段存在允许范围内的差异时，PB Lifter 可以合并原本兼容的骨骼链，并向合并组件写入一个聚合后的数值或曲线。

请小步调整容差：一次只启用一个字段，设为可接受的最小值，扫描后检查报告中列出的聚合结果，再进游戏测试。不要将**全部启用**作为通用优化手段。

**绝对值**容差直接比较数值差；**相对值**容差会按数值大小缩放允许差异。字段可以覆盖默认类型。对于曲线，PB Lifter 还要求关键帧数量、循环模式和加权关键帧模式一致。

### 排除规则

为绝不能改动的节点添加排除规则。选择**仅当前节点**只保护该节点上的 PhysBone；选择**当前节点及子节点**可保护整个子骨架。对于已知敏感的骨骼链，排除规则是最可靠的保护方式。

### 高风险放宽

所有高风险放宽默认关闭。每一项只会让原本被排除的候选项进入后续筛选；兼容性设置和分组要求仍然必须满足。

| 放宽项 | 仅应在以下情况下考虑 |
| --- | --- |
| 已禁用的组件 | 已确认组件启用或禁用时仍具备等价行为。 |
| 层级中未激活的组件 | 已验证其激活层级和构建后的行为。 |
| 实际允许抓取 | 已确认合并后抓取行为仍然一致。 |
| 已配置的 PhysBone 参数 | 已确认参数驱动的行为不依赖于组件彼此独立。 |
| 非 `Ignore` 多子节点模式 | 已测试合并组件改为 `Ignore` 模式后的链表现。 |
| Humanoid 骨骼映射路径 | 已在相关的移动和动画状态中检查受影响的人形骨骼路径。 |
| 组件自身激活动画 | 已检查激活过渡和重置行为。 |
| 受影响骨骼上的约束 | 已一同测试约束计算与模拟表现。 |

有两项保护不能关闭：数值属性被动画驱动的 PhysBone，以及激活动画切换根不同的候选项。PB Lifter 永远不会合并这两类情形。

## PB Lifter 会检查什么

对于有效根节点父级和激活动画切换根相同的候选项，PB Lifter 要求组件状态、PhysBone 版本、根节点关系、`Ignore Other PhysBones`、多子节点和积分模式、限制、碰撞体、权限、动画/重置设置、参数和骨骼链长度一致。数值字段和曲线也必须一致，除非你明确为对应字段启用容差。

构建时，PB Lifter 会读取 NDMF 的虚拟动画索引；重挂根节点后还会重映射动画路径，并在合并前将 `Ignore Other PhysBones` 转换为忽略 Transform。编辑器预览只索引 Avatar 直接引用的动画片段，因此如果此前的构建插件会生成动画曲线，最终构建可能比预览更加保守。

## 上传前验证

请在 VRChat 中对构建副本执行与 Avatar 使用方式相符的测试：

- 逐一开关每个受影响对象。
- 测试相关手势、FX 状态、参数、Contact 和约束。
- 在启用时测试抓取、摆姿、碰撞和禁用后重置行为。
- 执行会让合并链达到最大运动幅度的动作；涉及人形路径时也测试移动状态。
- 上传前与未优化 Avatar 对照检查。
